# 六级听力实验室 · 云同步版

以已上线的 v15 前端为基础，保留历年真题、整卷保留区、逐句精听、错题、手写、离线音频和 JSON 备份。原站独立保留。

## 本地验证

- Node.js 24：`npm ci`、`npm run build`、`npm test`、`npm start`。
- 打开 http://localhost:3000。没有数据库时仍可游客练习；`/api/status` 会如实返回 503。
- 后端测试使用本机嵌入式 PostgreSQL（PGlite），生产使用 PostgreSQL 和 pg 连接池。两项旧回归需要本地音频/审核附件；仓库干净检出时会标记为跳过，不会下载或提交原始资料。

## Altare 部署与回滚

1. App Hosting → GitHub → 选择本仓库的 `main`。根目录留空（使用仓库根目录），运行时 Node.js 24，应用位置选 Singapore。
2. 安装命令 `npm ci --omit=dev`；构建命令 `npm run build`；启动命令 `npm start`。健康探针如可配置，填 `/healthz`。
3. Storage → Postgres → 创建亚洲区域 Always Free 实例；在数据库页用 **连接应用** 注入 `DATABASE_URL`。如托管数据库使用独立证书，在 Altare 环境变量中设置数据库控制台下载的证书为 `DATABASE_CA_PEM`（可用 PEM 多行或用反斜杠 n 表示换行）。应用不会关闭 TLS 验证。
4. 使用平台 HTTPS 地址；若更换主站域名，在应用变量设置 `APP_ORIGIN` 为完整 HTTPS origin，不加尾斜杠。在变量中设置一个自行生成的长随机 `REGISTRATION_CODE` 才能注册。不要把机密放入仓库。注册后可删除邀请码变量，现有账号可继续登录。
5. 验证 `GET /healthz` 成功，且 `GET /api/status` 显示 `database: ready`。用独立浏览器配置验证登录、练习、离线重连和同步，确认后才迁移实际学习记录。
6. 如需回退，在 Altare 回滚到最近一个工作正常的动态版本，不删除数据库；旧静态站依然可访问。数据库有免费套餐快照，仍建议保留学习 JSON 备份并做一次恢复演练。

## 从旧站迁移

在看得到记录的原浏览器和**原网址**上，打开「资源与数据 → 下载备份 JSON」。到新站先导入备份，核对篇数与首答结果，登录后再点击「确认启用同步」。第二台设备同一账号登录，确认启用并核对同步结果。旧网址不能被新网址读取；换地址不会自动迁移。录音和音频离线文件需另行保存；手写可以通过 JSON 备份搬迁，但不参与云同步。

## 数据行为与下一步

- IndexedDB 仍是本机记录；保存和待发操作使用同一个本地事务。服务端按账号串行应用变更，重发同一操作只记一次。不同键可合并；同一键并发编辑以服务器最后接受的操作为准。导入首份设备快照不覆盖云端现有键或已删除的键，交卷历史去重后保留最早作答；缺失时间不编造。
- 今期同步范围：作答含草稿、交卷与完成记录、收藏、词汇笔记、选项划线、错题原因和练习时长。不上传离线文件、录音、手写、浏览器设置或单独导入的题库。未登录仍能离线练习；登出不会擦除本机数据。多账号使用独立浏览器配置。
- 分析页使用同步后的记录计算最近 7 天交卷活跃日、分题型首答表现和学习时长；非核验题不计分。
- 独立存储：构建时从原站拉取并校验 6 个固定版本题库/报告；当前音频若无本地包，由后端从原站读取。不把音频、教材 PDF、用户备份或数据库凭据提交到 GitHub。上线后可把有权复用的音频迁入 U3，并独立核验文件清单与范围请求，解除对旧站的依赖。
- 后续优先做备份恢复演练、注册/找回密码流程、实体平板与手机长期验证，再推进更详细的趋势分析。首版没有邮件找回密码。
